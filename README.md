# Справочник Атырауского филиала ТОО «ВЖДО» — деплой на Netlify

Теперь сайт сохраняет изменения администратора по-настоящему — на сервере,
через бесплатную серверную функцию Netlify (Netlify Functions) и
встроенное хранилище Netlify Blobs. Изменения сразу видят **все**
посетители сайта, без ручной перезаливки файлов.

## Структура проекта

```
├── index.html                    сам сайт
├── data.json                     резервная копия данных (на случай, если функция недоступна)
├── netlify.toml                  конфигурация Netlify (папка функций + маршрут /api/directory)
├── package.json                  зависимость @netlify/blobs для серверной функции
└── netlify/
    └── functions/
        └── directory.js          серверная функция: чтение/запись справочника + проверка пароля
```

## Как задеплоить (рекомендуемый способ — через Git)

1. Создайте новый репозиторий на GitHub и загрузите туда все файлы из этой папки
   (включая скрытые системные файлы Netlify не нужны — просто всё, что видите здесь).
2. Зайдите на [app.netlify.com](https://app.netlify.com/) → **Add new site** →
   **Import an existing project** → выберите этот репозиторий.
3. Настройки сборки Netlify подхватит автоматически из `netlify.toml`:
   - Build command: можно оставить пустым
   - Publish directory: `.`
   - Functions directory: `netlify/functions` (уже прописано в `netlify.toml`)
4. Нажмите **Deploy site**. Netlify сам установит `@netlify/blobs` из `package.json`
   и соберёт функцию — ничего вручную устанавливать не нужно.
5. После деплоя откройте сайт по выданному адресу (или подключите свой домен
   в Site settings → Domain management).

## Альтернатива — деплой через Netlify CLI (без GitHub)

```bash
npm install -g netlify-cli
cd путь/к/этой/папке
npm install
netlify login
netlify deploy --prod
```

## Первый вход администратора

- Пароль по умолчанию: **`atyrau2026`**
- Сразу после первого входа рекомендуется сменить пароль через
  панель администратора → «Сменить пароль» — новый пароль сохранится
  на сервере (в Netlify Blobs) и будет действовать для всех.

По желанию можно задать пароль ещё до первого входа: в Netlify зайдите в
**Site settings → Environment variables** и добавьте переменную
`ADMIN_PASSWORD` со своим значением — она будет использоваться, пока
пароль ни разу не меняли через сайт.

## Как это работает

- `GET /api/directory` — отдаёт текущие данные справочника (публично, без пароля)
- `POST /api/directory?action=login` — проверяет пароль администратора
  (сам пароль на сервер и в браузер никогда не «светится» в коде страницы)
- `POST /api/directory?action=save` — сохраняет изменения (требует верный пароль)
- `POST /api/directory?action=password` — меняет пароль администратора

Если по какой-то причине функция окажется недоступна (например, при
предпросмотре файла локально), сайт автоматически откатится на
резервный файл `data.json`, а панель администратора покажет кнопки
«Скачать / Загрузить data.json» для ручного резервного копирования.
